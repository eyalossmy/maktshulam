# מקטשולם

ניהול מק״טים פשוט: שם, מק״ט ותמונה, בלי כפילויות.

- **חסימת כפילויות** – שם ומק״ט מנורמלים (רווחים, מקפים, אותיות גדולות/קטנות, ניקוד) ונבדקים בזמן ההקלדה. בנוסף מוגדרים אינדקסים ייחודיים במסד הנתונים עצמו, כך שגם שמירה מלשונית אחרת נחסמת.
- **זיהוי תמונה כפולה** – טביעת אצבע חזותית (dHash) מזהה את אותה תמונה גם אם הועלתה בגודל או באיכות שונים.
- **אזהרה על שם דומה** – שמות שההבדל ביניהם הוא תו אחד מסומנים באזהרה.
- הנתונים נשמרים במכשיר (IndexedDB). אפשר לייצא ולייבא גיבוי JSON מתפריט ⋯.

אתר סטטי, בלי שלב build. להרצה מקומית:

```bash
npx http-server -p 4173
```
