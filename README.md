# מקטשולם

ניהול מק״טים פשוט: שם, מק״ט, ID, תמונה וקישור, בלי כפילויות. הנתונים נשמרים ב־Postgres (Neon), כך שהם משותפים בין כל המכשירים.

## איך זה עובד
- **מק״ט** הוא סוג מוצר (למשל `EVO-DRONE`), ויכולות להיות לו יחידות רבות.
- **ID** הוא מזהה ייחודי לכל יחידה (למשל `EVO-DRONE-001`).

## חסימת כפילויות
הכללים נמצאים ב־`lib/rules.js`. הדפדפן מריץ אותם בזמן ההקלדה, והשרת מריץ אותם שוב בכל שמירה, בתוך טרנזקציה נעולה:
- **ID** – ייחודי לגמרי, ויש עליו גם אינדקס ייחודי במסד הנתונים.
- **שם ↔ מק״ט** – לכל מק״ט יש שם אחד, ושם שייך למק״ט אחד בלבד. כשמשנים את השם של יחידה אחת, הוא מתעדכן בכל היחידות של אותו מק״ט.
- **תמונה** – טביעת אצבע חזותית (dHash) חוסמת את אותה תמונה במק״ט אחר, גם אם הועלתה בגודל או באיכות שונים.
- **השוואה מנורמלת** – רווחים, מקפים, אותיות גדולות/קטנות וניקוד לא משנים. `evo drone` ו־`EVO-DRONE` נחשבים אותו מק״ט.

ייצוא לאקסל (CSV) זמין מכפתור "ייצוא".
